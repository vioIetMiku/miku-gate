# 受管入口持久化与普通用户核心运行（dev.10开发）

## 操作流程

系统与诊断 → 新建受管入口：选择逻辑出口、核心/模板/客户端地址/端口，输入创建逻辑出口时的一次性入口密码（用于服务端核对绑定，不是管理员密码），明确保存确认和证书读取/REALITY网络同意。入口和逻辑出口均须停止才能保存或替换。

保存仅加密持久化，不开放端口或启动核心。先启动健康逻辑出口，再“启动已保存入口”。“停止受管入口”只停止Miku自己生成的子核心；停止逻辑出口会先停止入口，出口生命周期丢失也撤销子核心。重启不自动启动任何入口，不用数据库状态冒充进程活着。

客户端材料需明确“显示客户端导入（含凭据）”；API只返回客户端config/URI，不返回服务器TLS/REALITY私钥或本机Miku代理密码。导入材料是敏感凭据。运行态区分真实核心check、PID持有socket、业务握手未逐条验证，不把监听成功当完整公共业务验收。

## 显式核心授权

Linux `miku-gate serve` 增加 `--xray-core=绝对路径`、`--sing-box-core=绝对路径`。不指定则入口启动明确不可用，不自动执行发现的面板程序。

路径解析后要求可执行独立文件、根所有且整个目录链不可由组/其他用户改写；控制服务与子核心必须普通UID，启动通过系统setpriv继承no_new_privs，无有效Linux能力。现有x-ui非root安装目录不会因读摘要授权而被信任执行。

当前受管监听需1024以上端口；443低端口、专用账号和cgroup预算由后续安装服务明确授权。管理员不可把已有面板程序随便改归属来绕过；应安装经过校验的独立核心。此阶段不会安装任何软件、修改firewall、调用systemctl或重启已有核心。

## 配置与凭据保存

schema6新增managed_ingress，加密内容包括模板参数、随机客户端身份、REALITY服务器私钥/shortID、证书公私钥快照、本机代理认证。AES-GCM标签绑定稳定实例/出口；view不包含秘密，删除逻辑出口会级联删除材料。明文不落core临时配置文件；使用模板重新渲染后，证书/密钥以内存字段嵌入标准输入。

备份/升级须停止服务并一起保存数据库/WAL/同名.key；旧dev.8/9拒绝schema6，丢key不能恢复材料，不能自动生成假恢复key。入口绑定存在时拒绝单独轮换逻辑出口密码，避免失配；后续受控同步轮换再完善。目前需先停止并移除/重新绑定入口。

入口端口与逻辑出口本机代理端口跨表互斥，运行保存/删除/核心启动受操作锁保护。保存/渲染校验证书信任/有效期和素材绑定；REALITY旧探测过期（10分钟）需重新明确验证后保存，不无声对新IP重连。

## 实际运行器

先对内存配置执行官方核心check（6秒预算），不回显核心原始日志。启动后以/proc TCP地址/端口＋实际PID的FD/socket inode核验监听归属，并读UID、NoNewPrivs、CapEff；不是单纯“能连接某端口”就信任运行。5秒启动预算，端口冲突不抢占。

子进程使用parent-death SIGKILL且固定创建OS线程到Wait，控制服务异常死亡撤销子核心；显式停止只信号自己持有的Process，不按名称杀服务。出口租约结束也撤销入口。不支持把浏览器任意JSON、脚本、程序路径或环境变量传入执行器。

## 证据与边界

单元覆盖加密/重启身份稳定/缺密钥/跨出口密文拒绝、客户端秘密边界、错误proxy密码、未知核心拒绝、租约和修改互锁。已有六协议真实实验继续保留；新增实际native运行器实验（两核心、stdin证书/归属/UID/出口租约撤销）必须按精确源码另外回读，不能把新增测试说成已通过。

当前不是最终生产安装：专用核心账号/资源预算、systemd恢复、证书助手/续期、完整加密入口→公共VPN链路、核心升级备份回滚、域名或IP HTTPS管理仍未全部完成。状态不宣称data_verified，完整目标未缩减。
