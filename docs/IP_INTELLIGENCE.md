# 节点、实测出口和域名的归属/风险辅助（dev.12）

> 需管理员明确同意联网查询。信息查询走宿主网络的固定HTTPS元数据接口，不是业务流量直连后备；提供的是第三方资料，不承诺住宅、独享、匿名、解锁或“纯净”。已发布dev.11没有此界面。

## 在界面查询

- 节点库每行新增“归属 / ASN / 风险”：只查询近期官方缓存中该节点IP，界面不能提交任意IP替换候选。
- 出口详情真实运行卡新增查询按钮：先启动和连通性探测，实际出口健康、监听存在且最近5分钟有实测公网IP才允许。节点列表IP不能冒充真实出口；查询返回前再次核对本次运行/IP仍相同。
- 查询弹窗勾选“同意向固定第三方查询IP信息”后才联网。可另外输入域名，规范完整ASCII/IDNA域名解析公共IPv4，全部结果先排除私网/保留地址，只查询首个排序IP，不连接用户域名端口。
- 显示地区、城市、ISP/组织、BGP前缀、宣告ASN/holder、黑名单分项、来源/采集时间/缓存和路径解释。网站可用CDN/Anycast，IP地区不能证明网站经营者归属。

## 来源与真实性

| 数据 | 当前来源 | 明确限制 |
|---|---|---|
| 地理库、ISP/组织 | IPWHOIS.IO免费HTTPS | 接口无需key，有日额度/无SLA；拒绝、超额、错目标都显示未知 |
| BGP前缀、ASN | RIPEstat RIS network-info | 只显示与查询IP包含关系通过的前缀；多源宣告保留，最多2个ASN补名称 |
| ASN holder | RIPEstat as-overview | holder不等于住宅属性；不存在不从名称猜 |
| DNS黑名单辅助 | RIPEstat dns-blocklists | pending、不完整、failed/unsupported/限流均未知；不自动持续轮询 |
| 住宅/独享属性 | 未有可核验证据 | 始终未知，不据国家或ISP名称打纯净分 |

若任意黑名单明确listed，显示“部分来源列出”，不是恶意用途判决。只有所有返回的已知来源都明确notlisted且无pending，才显示“本次检查来源未列出”；它不等于纯净IP。尤其PBL等策略名单不代表恶意。收费安全数据/其他信誉站仍未集成，当前不伪造Tor/VPN/风控分。

## 请求预算与安全边界

固定 `stat.ripe.net` 与 `ipwho.is` 的HTTPS端口443，禁HTTP、重定向与环境代理；系统CA验证，DNS结果全公共IPv4后数字IP拨号。归属业务不对用户目标抓网页/扫端口。默认并行3类查询，总12秒、每响应128KiB、最多16 ASN与32黑名单来源；最多2 ASN名称补查。一个全局查询槽、间隔3秒、128条缓存，通常15分钟；pending/整体无数据1分钟。不会后台全节点批量压测，不安装新依赖。

API均需管理员会话/CSRF/同源与明确confirm。账户/代理密码、证书、VPN配置不发送给第三方，只发送目标IP或公共域名解析。停止出口不会为了补资料自动直连业务目标。

## API

```text
POST /api/nodes/{id}/intelligence  {"confirm":true}
POST /api/exits/{id}/intelligence  {"confirm":true}
POST /api/intelligence/domain     {"hostname":"www.cloudflare.com","confirm":true}
```

返回含来源/采集时间与未知状态的结构化资料。未知数据不会阻止合法出口使用；严格住宅策略在没有可靠证据时仍拒绝启动，不把这些元数据当放行住宅的凭据。
