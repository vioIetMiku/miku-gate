## 已执行的验证

- `go test -count=1 ./...`：通过；包括存储、身份、CSRF、配置校验、代理协议、目标地址策略和诊断测试。
- `go vet ./...`：通过。
- OpenVPN 配置校验器执行 5 秒有界 fuzz：369,015 次输入执行，无崩溃（不等于完整配置安全证明）。
- `npm --prefix web test`：6 项通过（过滤与 API 客户端行为）。
- `npm --prefix web run build`：TypeScript 检查和生产构建通过。
- `node scripts/smoke.mjs`：21 项 HTTP/CLI 真实服务检查通过，不使用假 API、不连接 VPN。
- Windows amd64 构建通过。
- Linux amd64 / arm64 交叉编译通过；**尚未在 Linux 运行，不等于生产可用**。

浏览器和 Linux 运行测试未完成，因此暂不提供“通过全部验证”的标记或伪造的运行截图。浏览器测试账户是隔离临时数据，不能用于实际管理。

## 这不是哪些功能的完成证明

- 不是 VPN 隧道建连、实际出口、DNS 路径或 kill switch 的运行证明。
- 不是住宅/独享/低风险 IP 的认证，也不是公共节点性能测试。
- 不是手机真机或完整键盘/读屏可访问性测试。
- 不是完整安全审计、依赖漏洞审计或软件分发许可审查。
